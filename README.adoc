== Guide d’installation

Ce guide décrit les étapes nécessaires pour installer et exécuter l’application *Bajon Consulting – Audit* en environnement local ou serveur, à l’aide de Docker.

=== Prérequis

Avant de procéder à l’installation, la machine hôte doit disposer des outils suivants :

* Docker
* Docker Compose

Aucune installation locale de Node.js, Java, Maven ou autres dépendances n’est requise.  
L’ensemble de l’environnement d’exécution est fourni via les conteneurs Docker.

---

=== Récupération du projet

Cloner le dépôt du projet depuis le gestionnaire de version :

[source,bash]
----
git clone https://github.com/summerflamme/Bajon-Consulting.git
cd Bajon-Consultin/Code
----

---

=== Configuration de l’environnement

Créer un fichier `.env` à la racine du projet afin de définir les variables d’environnement nécessaires.

Exemple de fichier `.env` :

[source,env]

IMPORTANT: Les variables destinées au frontend doivent obligatoirement être préfixées par `VITE_` afin d’être prises en compte lors du build.

---

=== Lancement de l’application

Depuis la racine du projet, exécuter la commande suivante :

[source,bash]
----
docker compose up -d --build
----

Cette commande :
* construit les images Docker du frontend et du backend,
* démarre les conteneurs en arrière-plan,
* rend l’application accessible automatiquement.

---

=== Accès à l’application

Une fois le déploiement terminé, l’application est accessible aux adresses suivantes :

* Frontend : `http://localhost`
* Backend (API) : `http://localhost:8080`

---

=== Arrêt de l’application

Pour arrêter l’ensemble des services et supprimer les conteneurs :

[source,bash]
----
docker compose down
----

---

=== Déploiement sur un serveur distant

Pour déployer l’application sur un serveur :

. Installer Docker et Docker Compose sur le serveur.
. Adapter les variables d’environnement (URL publique du serveur).
. Lancer l’application avec :
+
[source,bash]
----
docker compose up -d --build
----

Le frontend est exposé via le port 80 et le backend via le port 8080.

---

=== Notes complémentaires

* L’authentification est gérée par Supabase Auth via une API externe.
* L’application est destinée à un usage interne (client Bajon Consulting).
* La conteneurisation garantit une cohérence totale entre les environnements de développement et de production.
